Electrical contracting, electrical maintenance, solar installations and inspections - Midrand, Gauteng.
Phone 064 507 2571 | admin@elektraserve.co.za | www.elektraserve.co.za

## Files (all in one folder, upload every file to the root of the repository)
- index.html, about.html, services.html, portfolio.html, contact.html, appointment-request.html
- Photos (.jpg), logo.png, logo-mark.png, favicon.png, favicon.ico
- sitemap.xml, robots.txt, .nojekyll

## Publish on GitHub Pages
1. Create a repository, then Add file > Upload files.
2. Select ALL files in this folder (including .nojekyll) and drag them in. Images must be in the same place as the .html files.
3. Commit, then Settings > Pages > Deploy from a branch > main / (root) > Save.

## Appointment form
Sends straight to admin@elektraserve.co.za via FormSubmit. After the site is live, submit one test request, click the activation link FormSubmit emails to that address (check spam), then submit again. It only works on the live site.

## If photos do not show
A photo file was not uploaded, or was uploaded into a sub-folder. Photos must sit in the same folder as the pages. File names are case-sensitive.
